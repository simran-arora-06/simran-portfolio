# Simran Portfolio

A modern, animated single-page portfolio built with plain HTML, CSS and JavaScript. There is no build step.

## What's inside

- `index.html`: page structure and content
- `styles.css`: colours, layout and animations
- `script.js`: Three.js particle galaxy, scroll animations, progress bar

## Colours

Violet `#7C5CFF`, cyan `#22D3EE` and pink `#F472B6` on a deep navy `#0B1020` background.

## Run it locally

Open `index.html` in a browser. To serve it properly, run `python3 -m http.server` in this folder and visit `http://localhost:8000`.

## Deploy

Deployed as a static site on Render. Build command: none. Publish directory: the repository root.

## Make it yours

- Replace the placeholder photos from `picsum.photos` with your own images.
- Edit the project descriptions and GitHub links in `index.html`.
- Add your email or LinkedIn in the Contact section.
